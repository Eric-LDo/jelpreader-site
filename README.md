# Site do JelpReader

Landing page e política de privacidade do app JelpReader, publicadas no Netlify em https://jelpreader.jelpooth.com.br.

- `index.html` — página inicial com o vídeo de demonstração
- `privacy-policy.html` — política de privacidade, servida em `/privacy-policy` (link usado no Google Play)
- `app-ads.txt` — autorização de vendedores do AdMob
